# Biblioteca Digital UniFECAF

## Sobre o projeto

A Biblioteca Digital UniFECAF é um projeto acadêmico desenvolvido para a disciplina de Design Web. Seu objetivo é criar uma interface digital para facilitar a visualização e a organização de materiais de estudo por categorias, oferecendo uma experiência de navegação simples, intuitiva e acessível.

## Objetivos

- Desenvolver uma interface organizada e intuitiva.
- Facilitar a navegação entre categorias de materiais didáticos.
- Aplicar conceitos de design responsivo.
- Utilizar HTML e CSS na construção da interface.
- Adaptar a visualização para computadores, tablets e smartphones.

## Tecnologias utilizadas

- **HTML5:** estruturação do conteúdo.
- **CSS3:** estilização, layout e responsividade.

## Identidade visual

O projeto utiliza uma identidade visual inspirada no padrão da UniFECAF, com tons de azul-escuro, azul-esverdeado, cinza-claro e rosa. A organização visual busca manter a harmonia entre cores, tipografia e elementos da interface.

## Responsividade

A interface foi planejada para se adaptar a diferentes tamanhos de tela, proporcionando uma experiência de navegação em computadores, tablets e smartphones.
